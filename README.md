# Disaster Tweet Classifier

BERT-based deep learning model for classifying disaster-related tweets using Natural Language Processing (NLP).

## Overview

This project is a web-based NLP application that predicts whether a tweet is related to a real disaster or not. The application uses a BERT-based deep learning model for accurate text classification.

## Features

- Disaster tweet classification
- NLP preprocessing
- BERT-based prediction
- User-friendly web interface
- Real-time prediction

## Technologies Used

- Python
- FastAPI
- BERT
- Transformers
- PyTorch
- HTML
- CSS
- JavaScript
- Hugging Face
